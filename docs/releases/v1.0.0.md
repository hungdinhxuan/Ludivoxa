# Ludivoxa v1.0.0

Bản phát hành Ludivoxa đầu tiên, phát triển từ Interpreter của bquenin/qube.

## Tính năng

- OCR Anh/Nhật offline, chọn box hội thoại và lưu riêng theo game.
- Dịch bằng Ollama local hoặc OpenAI-compatible/GPU server LAN; mặc định sang
  tiếng Việt, giữ context và prompt tùy chỉnh, không tự fallback sang cloud.
- Overlay, TTS hoặc cả hai; Nano có 11 preset và clone giọng từ file local,
  đồng thời giữ 67 lựa chọn giọng Piper.
- Chống đọc lặp do nhiễu OCR/con trỏ; xử lý nền, cache và tổng hợp giọng đã lỗi thời.
- Đóng app cuối cùng tự tắt Ollama riêng và model runners; không tắt server
  local/LAN dùng chung.

## Cài đặt Windows x64 offline

Tải EXE và **cả ba file BIN** của release, để chung một thư mục rồi chạy EXE:

1. `Ludivoxa-1.0.0-Full-Offline-Setup.exe`
2. `Ludivoxa-1.0.0-Full-Offline-Setup-1.bin`
3. `Ludivoxa-1.0.0-Full-Offline-Setup-2.bin`
4. `Ludivoxa-1.0.0-Full-Offline-Setup-3.bin`

Tổng khoảng 4,9 GB; cần khoảng 6,4 GB cho app sau khi cài. Python, Ollama,
OCR/TTS models và HauhauCS Qwen3 4B Aggressive Q4_K_M đã có sẵn. Xem
`SHA256SUMS.txt` để kiểm tra file và `release-manifest.json` để đối chiếu bản build.
Các gói Source code tự động của GitHub không chứa runtime/model.

Mở Ludivoxa, chọn game → Start Capture → Configure OCR → Only selected box,
khoanh phần hội thoại rồi OK. Bản cài mới dùng Ollama riêng ở 127.0.0.1:11435.
Nâng cấp giữ cấu hình hiện có. Tên file `Interpreter.exe` và vị trí cấu hình
cũ được giữ để tương thích, còn app/Start menu mang tên Ludivoxa.

OCR, dịch và TTS có thời gian xử lý riêng; đoạn dài vẫn có thể chậm. TTS đi kèm
đọc tiếng Việt. Bản build chưa ký số; live FPS và máy chủ LAN riêng chưa được
đo trong lượt xác minh này. Không kèm mẫu clone giọng cá nhân.
