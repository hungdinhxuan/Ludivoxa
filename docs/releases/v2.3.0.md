# Ludivoxa v2.3.0

- Chọn **Tiếng Việt** hoặc **English** tại **Interface language** ở cuối
  thanh bên, rồi mở lại Ludivoxa để đổi giao diện.
- Màn hình **Chơi** thu gọn cài đặt giọng đọc và vẫn hiển thị tên Qwen3-TTS
  khi dùng giọng clone. **Cấu hình OCR** nằm ở thanh trên. Hồ sơ game, giọng
  nhân vật và chẩn đoán nằm trong menu **Công cụ**.
- Các trang cài đặt cuộn trong cửa sổ. Nút **Áp dụng** của trang **Bộ xử lý**
  nằm cố định bên dưới để dễ bấm trên màn hình nhỏ.

## Cập nhật Windows x64

Mở **Updates → Check for updates**. App ưu tiên gói vá nếu các tệp cài đặt
khớp v2.2.1. Các bản cài khác dùng `Ludivoxa-2.3.0-App-Update.exe`. Cả hai
gói giữ cấu hình, model, mẫu giọng và Ollama. Đối chiếu `SHA256SUMS.txt`
khi tải thủ công.
