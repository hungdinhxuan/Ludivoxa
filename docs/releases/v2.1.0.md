# Ludivoxa v2.1.0

- Thêm clone giọng offline cho tiếng Anh, Nhật, Hàn và Trung giản thể/phồn thể.
  Chọn một mẫu WAV hoặc MP3 trong **Clone from audio** để nghe thử, tự đọc hội
  thoại mới hoặc phát lại từ **History**.
- Tính năng dùng **Qwen3-TTS 0.6B Base** qua llama.cpp trên cùng máy. Cài riêng
  runtime và cặp GGUF khoảng 762 MB nếu cần tính năng này. Bản dịch và mẫu giọng
  đi qua loopback. Chế độ tiếng Việt tiếp tục dùng VieNeu hoặc Piper.

[Cách cài Qwen3-TTS và chọn giọng](https://github.com/hungdinhxuan/Ludivoxa/blob/v2.1.0/docs/USER_GUIDE.md#clone-giọng-đa-ngôn-ngữ)

## Cập nhật Windows x64

Mở **Updates → Check for updates**. App ưu tiên gói vá nếu tệp v2.0.1 khớp
bản phát hành. Bạn cũng có thể chạy `Ludivoxa-2.1.0-App-Update.exe` và chọn
thư mục đang cài. Cả hai gói giữ `config.yml`, model, mẫu giọng và Ollama.
Đối chiếu `SHA256SUMS.txt` khi tải thủ công.
