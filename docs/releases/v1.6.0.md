# Ludivoxa v1.6.0

- **Chinese** đọc tiếng Trung giản thể và phồn thể bằng PaddleOCR offline.
- **Korean** đọc tiếng Hàn bằng model PP-OCRv5 riêng, có sẵn trong gói cập nhật.
- Chọn ngôn ngữ ở **Engines → Source language** hoặc lưu riêng trong
  **Game profile…**. App nạp một model OCR theo ngôn ngữ đã chọn và truyền
  ngôn ngữ đó vào prompt dịch. **Auto** dành cho hội thoại trộn Anh/Nhật.

## Cập nhật Windows x64

Mở **Updates → Check for updates**. Bản cài v1.5.0 khớp tệp gốc có thể dùng
`Ludivoxa-1.6.0-Delta-from-1.5.0.exe`. Các bản cài khác dùng
`Ludivoxa-1.6.0-App-Update.exe`. Cả hai gói giữ cấu hình, giọng, model đã cài
và Ollama. Đối chiếu SHA-256 khi tải thủ công. Bộ cài chưa ký số.

Nếu cài lần đầu, dùng EXE và ba tệp BIN của bộ offline v1.1.1 trước, sau đó
áp dụng gói cập nhật chuẩn. [Bộ offline v1.1.1](https://github.com/hungdinhxuan/Ludivoxa/releases/tag/v1.1.1)
