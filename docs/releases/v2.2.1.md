# Ludivoxa v2.2.1

- **Play → Session** hiển thị **Qwen3-TTS Base (local clone)** khi chọn
  tiếng Anh, Nhật, Hàn hoặc Trung giản thể/phồn thể. Hướng dẫn thiết lập
  hiện dưới tên model nếu chưa cấu hình máy chủ cục bộ và mẫu giọng.
- Khi quay lại tiếng Việt, mục Voice hiển thị các giọng preset tiếng Việt.

## Cập nhật Windows x64

Mở **Updates → Check for updates**. App ưu tiên gói vá khi tệp cài đặt khớp
v2.2.0. Các bản cài khác dùng `Ludivoxa-2.2.1-App-Update.exe`. Cả hai gói
giữ cấu hình, model, mẫu giọng và Ollama. Đối chiếu `SHA256SUMS.txt` khi tải
thủ công.
