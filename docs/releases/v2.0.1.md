# Ludivoxa v2.0.1

- Icon bong bóng thoại và sóng âm mới cho Ludivoxa, bộ cài Windows và wiki.
- Windows có nhiều kích thước icon để hiển thị rõ trên thanh tác vụ,
  shortcut và File Explorer.

## Cập nhật Windows x64

Mở **Updates → Check for updates**. Updater ưu tiên gói vá từ v2.0.0 khi tệp
app khớp bản phát hành. Bạn cũng có thể chạy `Ludivoxa-2.0.1-App-Update.exe` và
chọn thư mục đang cài Ludivoxa. Cả hai gói giữ `config.yml`, model và Ollama.
Đối chiếu `SHA256SUMS.txt` khi tải thủ công.
