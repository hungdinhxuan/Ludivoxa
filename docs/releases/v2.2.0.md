# Ludivoxa v2.2.0

- **Game Profile → Prompt mode** hỗ trợ **Append to Engines prompt** để thêm
  thuật ngữ và quy tắc xưng hô riêng của game vào prompt chung, hoặc
  **Override Engines prompt** để dùng prompt riêng.
- Profile mới mặc định Append. Profile cũ có prompt giữ chế độ Override.
- Có thể viết prompt bằng tiếng Việt và dùng `{source_language}` cùng
  `{target_language}`. Cả dịch trực tiếp lẫn dịch lại từ History dùng chế độ
  đã chọn cho game.

## Cập nhật Windows x64

Mở **Updates → Check for updates**. App dùng gói vá khi tệp cài đặt khớp
v2.1.0. Các bản cài khác dùng `Ludivoxa-2.2.0-App-Update.exe`. Cả hai gói
giữ cấu hình, model, mẫu giọng và Ollama. Đối chiếu `SHA256SUMS.txt` khi tải
thủ công.
