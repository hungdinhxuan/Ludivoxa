# Ludivoxa v2.4.0

- Sửa lỗi nút **Check for updates** mở thành cửa sổ riêng khi khởi động.
  Nút giờ nằm trong tab **Updates**, còn kiểm tra tự động chạy trong nền nếu bạn bật.
- Mở Ludivoxa với `--api` để dịch văn bản và xuất giọng đọc WAV hoặc PCM từ script.
  API hỗ trợ ngữ cảnh theo phiên, prompt theo game và kết nối LAN có token.
- Capture desktop được ưu tiên mặc định. Dùng `--api-share-capture` nếu muốn gọi
  API đồng thời trong lúc capture.

## Cập nhật Windows x64

Mở **Updates → Check for updates**. App ưu tiên gói vá khi các tệp đã cài
khớp v2.3.0. Các bản cài khác dùng `Ludivoxa-2.4.0-App-Update.exe`. Hai gói
giữ cấu hình, model, mẫu giọng và Ollama. Khi tải thủ công, đối chiếu `SHA256SUMS.txt`.
