# Ludivoxa v2.0.0

- Gói Python, module và lệnh khởi chạy dùng tên `ludivoxa`. Các script cài đặt
  từ mã nguồn trong repo này.
- Trên Windows, shortcut và bộ cài dùng `Ludivoxa.exe`. Khi nâng cấp, bộ cài
  giữ `config.yml`, model OCR/TTS và Ollama đã cài.
- Cấu hình người dùng và log mặc định nằm trong `~/.ludivoxa`. Cấu hình ở vị
  trí cũ được đọc khi chưa có cấu hình mới. App lưu thay đổi vào thư mục mới.

## Cập nhật Windows x64

Mở **Updates → Check for updates**, hoặc tải `Ludivoxa-2.0.0-App-Update.exe`
và chọn thư mục Ludivoxa đang cài. Bản này dùng gói cập nhật chuẩn để chuyển
sang tên tệp chạy mới. Đối chiếu `SHA256SUMS.txt` khi tải thủ công. Bộ cài chưa ký số.

Nếu cài lần đầu, chạy EXE với ba tệp BIN của bộ offline v1.1.1, sau đó áp dụng
gói cập nhật v2.0.0. [Bộ offline v1.1.1](https://github.com/hungdinhxuan/Ludivoxa/releases/tag/v1.1.1)
